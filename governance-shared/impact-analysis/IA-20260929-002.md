# Impact Analysis

## CR ID

CR-20260929-002

## Summary

4.1.1 让对不上恰好一条已有需求的已拆源保持独立，并把相关编号写进摘要页的参见。版本戳不再被这两类情况挡住。schema 保持 0.17.0。这是规则修复，版本是 patch。

## Affected Layers

| Layer | Affected | Notes |
|---|---|---|
| Contract Layer (SKILL.md / skill.json / contracts/) | yes | 版本号。版本检查那句改为独立源不挡盖戳 |
| Execution Rules (references/01~23) | yes | 07 升级补链；16 §2.1b；20 盖戳条件 |
| Templates (assets/templates/) | no | 无新字段 |
| Scripts (scripts/) | yes | 编译的已绑和参见；迁移只增加 4.1.1 说明行 |
| Workspace Schema | no | 0.17.0。不新增必填目录 |
| Tests (tests/) | yes | 模块 97、98 改预期；模块 99 五行。合计 1099 |

## Affected Capabilities

| Capability | Impact | Risk | Need Regression |
|---|---|---|---|
| 升级盖戳 | 对不上恰好一条需求不再挡住；三类剩余失败仍挡住 | 高 | 是 |
| 摘要页 | 已绑增加独立；参见增加反向一跳和多条需求编号 | 高 | 是 |
| 旧摘要页 | 不整页重写；允许改已绑和参见 | 高 | 是 |
| 需求与工作包 | 恰好一条仍补边；没包仍建待确认包 | 中 | 是 |
| 查询 | 不把参见扫进每次查询 | 低 | 否 |

## Rollback

技能包回到标签 v4.1.0（d31366d）。schema 不回退。已经写出的「独立」和参见可以留下。已经建出的待确认包可以留下，旧编译器把它们当成普通待确认包。
