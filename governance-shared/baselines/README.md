# Baselines（版本基线快照）

## 用途

每个发布版本的包内容快照，用于发布对照、回归比对与审计追溯。**只增不改**：历史基线一经建立即冻结，不得回填或改写内容。

## 目录结构（v3.1.0 起）

```
baselines/{version}/
├── ChronoPM-Project/    # 单项目主包快照（3.1.1+ 强制；3.1.0 为平铺首版，audit 豁免）
└── ChronoPM-Portfolio/  # 项目集伴生包快照
```

≤3.0.0 的历史基线为单包时代冻结快照，结构保持原样不动。
