# 共享人力与流转只读聚合（V-3 配套）

人员实体的唯一事实源在各成员项目：`resources/resource-register.md` + `resources/transfer-log.md`。本包只做跨项目指针与实时视图。

## 1. 集层允许的指针文件

`portfolio/resources/shared-resource-index.md`（跨项目共享资源索引）：

| 字段 | 说明 |
|------|------|
| 姓名 | |
| 参与子项目 | PRJ-NNN 列表（指向各项目 register） |
| 共享状态 | 导航用：多项目共享 / 临时支援。人属性以各项目登记为准 |

`portfolio/resources/transfer-index.md`（跨项目流转索引）：

| 字段 | 说明 |
|------|------|
| Transfer ID | 指向发生流转的项目 transfer-log（兼容 `RTF-YYYYMMDD-NNN` 与时间戳号） |
| 姓名 | |
| 流转方向 | 如 PRJ-001 → PRJ-003 |
| 日期 | YYYY-MM-DD |

索引只作导航。禁止把可用性、排期、配置率、工时、能耗写入上述文件。同一人出现在 ≥2 个项目 register 时，应提示登记进 shared-resource-index（确认后只写指针）。索引不存在时，直接从各项目 register 实时聚合，不创建空文件充数。

## 2. 动态视图（禁止落盘）

查询或集周报需要人员全景时，实时读：

- 各项目 resource-register 表格行
- 相关日期 todos/{date}/{姓名}.md 的 §0 快照（冲突以 register 为准）
- 各项目 transfer-log 本周新增行

输出可用性摘要、排期冲突、人力配置率。周报中的配置率表是当期快照，不得被后续查询当数据源。

## 3. 漂移提示，不静默改项目文件

| 现象 | 本包行为 |
|------|----------|
| A 记王某同时在 B，B 无王某 | 提示双边不一致 → 建议更新清单，不改 A 或 B |
| 同一人不同项目姓名写法不同 | 「可能存在身份映射问题」，请集经理确认是否同一人 |
| 分配比例跨项目合计 >100% | T1 冲突提示 |
| 共享人在一项目改为请假/离场，其他项目仍在岗 | 提示是否到其他项目同步（清单），不代同步 |
| register 与该项目 project-context 团队列表不一致 | 差异报告，不自动改任一侧 |
| 日报/周报出现未入 register 的人 | 候选资源变更，不自动入册 |

禁止：为「保持一致」把 A 项目字段覆盖到 B；禁止改成员项目 transfer-log「补一条集层看到的流转」。

## 4. 资源风险只提示

命中下列条件时提示，并建议在**主归属项目** risk-register 登记（V-9），本包不写风险实体：

| 编号 | 条件 | 等级 |
|------|------|------|
| RR-01 | 关键岗位无 B 角 | 高 |
| RR-02 | 同一人同时参与 ≥2 个 P0/P1 项目 | 高 |
| RR-03 | 请假但仍承担关键未办结待办 | 高 |
| RR-04 | 抽调导致原项目关键任务无人负责 | 高 |
| RR-05 | 各项目分配比例合计 >100% | 高 |
| RR-06 | 计划离场早于关键里程碑 | 中 |
| RR-07 | 核心角色缺失（无后端/无测试/无产品，以该项目计划为准） | 高 |
| RR-08 | 连续流转 ≥3 次 | 中 |

## 5. 与单项目结转的边界

成员项目 ChronoPM-Project 在结转时提示「共享人力请到各项目分别结转」。本包：

- 不替任何项目做结转。
- 查询某人未办结待办时按 R18 跨项目列出，便于集经理看到漏结转，仍走建议更新清单。
