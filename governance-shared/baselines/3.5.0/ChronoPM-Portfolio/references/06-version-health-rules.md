# 集级健康巡检（V-10）

进入工作区或集经理要求「健康检查 / 巡检」时执行。只读检查 + 对话报告；可把报告落 `portfolio/reports/`（派生产物，须 generated_from + updated + stale）。禁止为「修好」而写成员项目文件。

## 1. 双包版本

| 对象 | 读取 | 期望 |
|------|------|------|
| 本包 | Skill `VERSION` / `skill.json` | 3.0.0 线与 Project 包同号发布 |
| 集级工作区 | `ai/.skill-version.json` | skillName=`chrono-pm-portfolio`；skillVersion ≤ 本包 VERSION |
| 各成员项目 | `projects/{名}/ai/.skill-version.json` | skillName=`chrono-pm-project`（兼容 `chrono-pm`） |

两包版本号发布时应相同。巡检若发现成员项目 skillVersion 与本包主版本（MAJOR.MINOR）差距 ≥1 个 MAJOR，列入报告，不自动升级对方。

集级 `.skill-version.json` 只约束本联邦工作区整体；项目级只约束该项目 ai。本包因版本降级**不得要求**项目内单项目对话停止工作——那是 Project 包自己的反向校验。

## 2. 反向校验

**Skill 版本必须 ≥ 工作区版本。**

| 比较 | 命中 | 行为 |
|------|------|------|
| 本包 VERSION < 集级 skillVersion | 工作区由更高版本创建 | 立即提示下载 ≥ 该版本的 Portfolio；**只读降级**：可查询已理解结构，禁止写 `portfolio/`、禁止「升级工作区」 |
| 本包 VERSION < 某成员 skillVersion | 成员项目更新 | 提示升级本包；该成员不纳入聚合（与 03 号挂载校验一致），降级不蔓延到其他已通过成员 |
| 本包 VERSION ≥ 成员 skillVersion | 正常 | 可聚合；成员侧缺新字段则按缺项降级展示，不写回补齐 |

禁止低版本规则改高版本结构。

## 3. 孤儿 / 失效路径

| 类型 | 判定 | 处置 |
|------|------|------|
| 孤儿目录 | `projects/{名}/` 存在但未登记 | V-1 提示登记，须确认 |
| 失效索引 | 索引有、目录无，或 `{名}/ai/` 不存在 | 提示清理索引，须确认 |
| 空挂载 | 有 `{名}/` 但无 `ai/` 或 ai 无 todos+context+.skill-version.json | 挂载失败，不聚合 |
| 旧路径残留 | 索引管理路径仍为 `ai/projects/{名}/`（缺一层 ai） | 提示更正索引 |

不删除磁盘上的孤儿目录（写禁及于成员区；`projects/` 本身亦非本包创建物）。

## 4. 防套娃复查

对每个 `projects/{名}/ai/` 检查是否存在 `portfolio/` 或 `projects/`。命中：告警、拒绝聚合该项、不自动删除。细则见 03 号 §3。

## 5. 配置型文件跨项目漂移

每成员项目各自一份：

- `context/pm-profile.md`
- `context/domain-glossary.md`
- `context/entity-registry.md`

巡检比对（最小读取：编号行 / 词条键 / 实体清单表，不读全文）：

| 结果 | 行为 |
|------|------|
| 一致 | 通过 |
| 漂移（同键不同值、一侧缺失内置 DF、实体枚举不一致） | **提示集经理裁决合并口径** |
| 一侧缺失整文件 | 记录缺失；补建须到该项目 Project 对话 |

**禁止静默同步。** 不得把「主副本」覆盖到其他项目。裁决结果如需改某项目文件 → V-9 建议更新清单，分项目执行。

pm-profile 仅比对 DF-NNN 编号是否齐全、状态是否可识别；不把某项目的个性化 PF 正文强制对齐到其他项目。

## 6. 巡检输出

固定段落：

1. 版本：本包 / 集级 / 各成员 skillVersion 与结论（正常 / 只读降级 / 剔除聚合）。
2. 挂载：通过 / 失败原因。
3. 孤儿与失效路径清单。
4. 套娃告警。
5. 配置漂移表：文件 × 项目 × 差异摘要 × 建议（裁决，不自动同步）。
6. 建议更新清单（若有需人处理项）。

成功则一句话摘要 + 报告可落盘；失败与告警全量输出。
