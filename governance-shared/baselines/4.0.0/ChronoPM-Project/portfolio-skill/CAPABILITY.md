# portfolio-skill — 能力目录（不是独立 Skill）

当前版是 ChronoPM-Project 内的能力目录，**禁止**命名为 `SKILL.md`。宿主不得把本目录扫成第二个 Skill。

- **何时加载**：当前根同时有 `ai/portfolio/` 与 `ai/projects/`，或用户做跨项目归集。由 ChronoPM-Project 加载 `references/`。
- **边界**：只查、不手搓成员正文。手递写入仍调用 Project 的写过程，`--project-root` 是成员根。
- **工作区**：`ai/portfolio/` 与 `ai/projects/{名}/ai/` 的形状与两个技能时期相同。
