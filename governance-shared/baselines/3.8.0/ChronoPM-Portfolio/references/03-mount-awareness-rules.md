# 挂载、动态感知与防套娃（V-1）

## 1. 挂载流程

集经理将项目 `ai/` 包接入本联邦工作区：

```
1. 在 ai/projects/ 下新建与项目同名的目录
2. 将项目 ai 包解压为 ai/projects/{名}/ai/   （内部即完整单项目工作区）
3. 本包执行挂载校验（只读检查，不改包内文件）
4. 校验通过 → ASK 收编进 project-index（须 PM 点头）
5. 校验失败 → 列出缺项，拒绝收编，不参与聚合。`{名}/ai/` 缺失 = 不收编
6. 收编成功 → 自动扫描该项目词库 confirmed 表格行，写入/更新 portfolio/context/glossary-index.md（见 §7）。无后台盯盘。
```

**挂载校验（三项全过才提示登记）：**

| 检查 | 通过条件 | 失败 |
|------|----------|------|
| 结构完整性 | `{名}/ai/` 下必含 `todos/`、`context/`、`.skill-version.json` | 列出缺失；可提示补建须到该项目 ChronoPM-Project 对话执行 |
| 版本正向 | 该项目 `.skill-version.json` 的 skillVersion **≤** 本 Portfolio Skill 版本 | 提示「成员项目由更高版本创建，请升级 Portfolio 至 ≥ {项目版本}」；本包对该项目只读降级且**不纳入聚合**直至升级 |
| 防套娃 | `{名}/ai/` 内不存在 `portfolio/` 或 `projects/` 目录 | 告警「套娃结构」，拒绝聚合 |

skillName 兼容：`chrono-pm-project` 与历史 `chrono-pm` 均视为单项目包。

校验只读。本包不得为了「补齐结构」在成员项目内创建缺失目录或文件。

## 2. 动态感知

每次进入工作区、以及每次跨项目查询前：

1. 列出 `ai/projects/` **一级**目录名（不递归下级）。
2. 读取 `portfolio/context/project-index.md` 子项目清单。
3. 比对：

| 发现 | 行为 |
|------|------|
| 目录有、索引无 | **ASK 收编**：提示「发现新项目 {名}，要不要收进来？」给出建议行（PRJ 编号/管理路径=`ai/projects/{名}/ai/`/状态待填）。**收编须集经理点头**后才写入 project-index |
| 索引有、目录无 | 提示清理失效条目；确认后才从索引删除或标记失效 |
| 两边都有 | 进入挂载校验（若本会话尚未校验） |

**扫描只发现候选，收编仍需确认。** 禁止把扫描结果直接当成正式成员写入索引。禁止用「扫一遍文件夹」代替 project-index 作为查询范围权威源。

**无后台盯盘。** 助手不会在有人把项目包拷进 `projects/` 的那一秒自己醒来。只在下次集层对话（进入工作区 / 跨项目查询前）才扫一级目录。

**结构门槛：** 必须是 `{名}/ai/`（含 `todos/`、`context/`、`.skill-version.json`）。`{名}/ai/` 缺失 → **不收编**、不建词库对照，白话说明缺什么。套娃（`{名}/ai/` 内再有 `portfolio/` 或 `projects/`）→ 告警，拒绝收编。

新登记字段最低集：项目 ID（PRJ-NNN，短号不变）、子项目名称、管理路径、PM、状态、优先级、是否纳入周报。可选「下级集工作区路径」见 §5。

## 3. 防套娃硬约束

`ai/projects/{项目名}/ai/` 内 **禁止** 存在：

- `portfolio/` 目录
- `projects/` 目录

即：项目 ai 不得再是集工作区。挂载校验与 V-10 均检查。命中：

1. 告警，写明路径。
2. 该项目不参与任何 V-2～V-12 聚合。
3. 不自动删除套娃目录（写禁）。内部 V-9 可建议「拆除套娃后重新挂载」，由人处理。对外白话，不对用户说「建议更新清单」。

## 4. 查询自动路由

1. 范围默认 = project-index 中状态非「已取消」、校验通过的一级成员。
2. 「是否纳入周报=否」的项目：不进 V-5 集周报，但仍可被点名查询。
3. 用户不指定项目时，按索引自动遍历；指定则子集。
4. 未登记目录：发现后走 §2 提示，**先登记后聚合**。

## 5. 下级集工作区路径（本期不聚合）

project-index 可选列「下级集工作区路径」：登记另一个集工作区的路径，供组合经理关联查看。

- 仅登记，**不参与本期任何聚合**（禁止 Portfolio-of-Portfolio 递归读取）。
- V-1 / V-2 范围固定为一级成员项目。
- 查询时若用户问及该路径，只回显已登记路径，提示「本期不展开下级集」。

## 6. 管理路径口径

v3.0.0 联邦协议：管理路径 = `ai/projects/{名}/ai/`（多一层 `ai/`）。索引中若仍为旧路径 `ai/projects/{名}/`，提示集经理更正索引；读取时若 `{名}/ai/` 存在则用新路径，旧路径仅作兼容探测，不写回成员项目。

## 7. V-1 登记成功后的术语指针（V-12）

**收编须 PM 点头。** 点头且挂载校验通过、project-index 写入成功之后，**自动**（不再问第二次）：

1. 只读该项目 `context/domain-glossary.md` **表格行**（原词 / 标准词 / 状态 / G 号），不读释义正文。
2. 只收录 **confirmed** 条目；pending 不进集层。
3. 按 `assets/templates/glossary-index-template.md` 创建或更新 `portfolio/context/glossary-index.md`。只存指针，不存全文。
4. 同一原词在已收编项目间标准词不一致 → 记漂移，走内部 V-9，不代改成员词库。

集经理说「刷新术语索引」时可按已登记成员全量重建。查询命中指针后校验目标条目仍存在；不存在则标 stale 并提示刷新。

禁止：未点头就写 project-index 或 glossary-index；把未收编目录的词库抽进索引；把集层索引当权威词库写回成员项目。
