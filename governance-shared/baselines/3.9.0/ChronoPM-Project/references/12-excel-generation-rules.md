# Excel 生成规范

本规则定义 ChronoPM 各文档类型导出为 Excel 文件时的结构规范。AI 生成 Excel 文件时必须遵循本规范，确保导出文件与用户原始项目管理 Excel 结构一致。

---

## 0. 通用原则

### 0.1 与 xlsx 技能配合

生成 Excel 文件时，必须同时加载 xlsx 技能（SKILL.md），遵循其核心原则：
- **公式优先**：用 Excel 公式而非硬编码值
- **零公式错误**：生成后必须通过 recalc 校验
- **视觉美观**：统一字体、表头样式、列宽适配
- **保留模板**：编辑已有文件时匹配原有格式

### 0.2 生成路径

Excel 文件生成到 `ai/outputs/{batch_id}/files/` 目录下（v2.1.0 起 outputs/ 位于 ai/ 内，遵循 `11-output-artifact-rules.md`）。

### 0.3 文件命名

格式：`{scope}-{document_type}-{period_or_date}-{version}.xlsx`

### 0.4 通用样式

| 元素 | 规范 |
|---|---|
| 字体 | 微软雅黑 10pt（表头加粗 11pt） |
| 表头行 | 背景色 #4472C4，白色字体，居中对齐 |
| 数据行 | 自动行高，顶端对齐 |
| 冻结窗格 | 冻结首行（A1） |
| 网格线 | 显示 |
| 列宽 | 根据列内容自动适配，最小 8，最大 50 |
| 日期格式 | YYYY-MM-DD（文本格式，避免 Excel 自动转换） |
| 百分比 | 0% 格式 |
| 空值 | 留空，不填 N/A 或 - |

### 0.5 数据验证下拉框通用规则

凡是状态类、类别类、是否类字段，必须设置数据验证下拉框，不允许自由输入。

### 3.3 公式

**N列（是否延期）公式：**

```
=IF(AND(L2<>"",M2<>"",M2>L2),"是","否")
```

若实际解决日期为空但已超过计划日期，公式变体：

```
=IF(L2="","",IF(M2<>"",IF(M2>L2,"是","否"),IF(TODAY()>L2,"是","否")))
```

## 5. 成本测算表 Excel 规范

### 5.1 Sheet 结构

| Sheet 名 | 内容 |
|---|---|
| 成本测算 | 成本结构汇总（人力/第三方/其他/税金/风险预备金） |
| 人力成本明细 | 按人员列出明细行（姓名/日薪/天数/小计）— 询问式细化 |
| 模块对比 | 本项目模块/工作包的合同额/成本线/投入对比（可选） |

### 5.2 成本测算 Sheet

| 行 | A列 | B列 | C列 | D列 |
|---|---|---|---|---|
| 1 | 成本类别 | 成本明细 | 测算金额（元） | 测算说明 |
| 2 | 人力成本 | 项目管理岗 | =人力成本明细!D2 | X人 x XX元/月 x XX月 |
| 3 | | 产品与需求岗 | =人力成本明细!D3 | |
| 4 | | 开发岗 | =人力成本明细!D4 | |
| 5 | | 测试与安全岗 | =人力成本明细!D5 | |
| 6 | 人力小计 | | =SUM(C2:C5) | |
| 7 | 第三方成本 | 第三方工具/组件 | | |
| 8 | 第三方小计 | | =SUM(C7:C7) | |
| 9 | 其他直接成本 | 差旅与招待 | | |
| 10 | 其他小计 | | =SUM(C9:C9) | |
| 11 | 税金 | 增值税及附加 | =C6*税率 | 按X%增值税+附加 |
| 12 | 风险预备金 | 需求变更/返工 | =C6*预备金比例 | 按人力成本X%计提 |
| 13 | 总成本合计 | | =C6+C8+C10+C11+C12 | |
| 14 | 项目毛利 | | =合同额-C13 | |

**公式说明：**
- C列金额必须使用公式引用 `人力成本明细` Sheet，不可硬编码
- 税率和预备金比例应放在独立单元格（如 D11 注明税率值），公式引用该单元格
- C6 人力小计 = `=SUM(C2:C5)`
- C13 总成本 = `=C6+C8+C10+C11+C12`
- C14 毛利 = `=合同额单元格-C13`

### 5.3 人力成本明细 Sheet（询问式细化）

**AI 在生成成本测算表时应询问用户：**

```markdown
成本测算表需要填写人力成本明细。请提供以下信息（可按角色汇总或按个人列出）：

1. 按角色汇总模式：
   - 项目管理岗：X人，XX元/月，XX月
   - 开发岗：X人，XX元/月，XX月
   
2. 按个人明细模式：
   - 姓名 / 角色 / 日薪(元) / 投入天数 / 小计(=日薪×天数)

是否需要按个人列出明细？还是按角色汇总即可？
```

**按个人明细模式结构：**

| 列序 | 列头 | 数据验证 | 说明 |
|---|---|---|---|
| A | 姓名 | - | |
| B | 角色 | 下拉：项目管理/产品/后端开发/前端开发/测试/DBA/其他 | |
| C | 日薪（元） | - | 蓝色字体（硬编码输入值） |
| D | 投入天数 | - | 蓝色字体 |
| E | 小计（元） | 公式：=C2*D2 | 黑色字体（公式计算结果） |

**E列公式：** `=C2*D2`（逐行）

**成本测算Sheet的C2单元格引用：** `=SUMIF(人力成本明细!B:B,"项目管理",人力成本明细!E:E)`

### 5.4 模块对比 Sheet（本项目内，可选）

| 列序 | 列头 | 说明 |
|---|---|---|
| A | 模块/工作包 | 本项目模块名称 |
| B | 合同金额（万） | 蓝色字体（硬编码） |
| C | 50%成本线（万） | 公式：=B2*0.5 |
| D | 拟投入人月 | 蓝色字体 |

## 9. 生成流程与确认

### 9.1 生成前确认

AI 生成 Excel 前必须：

1. 读取 `project-brief.md` 确认项目信息
2. 读取对应 Markdown 事实源文件获取数据
3. 询问用户需要的 Excel 类型（参见 `11-output-artifact-rules.md` 格式确认规则）
4. 成本测算表额外询问"按角色汇总还是按个人明细"
5. 创建输出批次目录

### 9.2 生成后验证

Excel 文件生成后必须：

1. 使用 xlsx 技能的 `recalc` 模块校验公式
2. 使用 xlsx 技能的 `audit` 模块审计公式结构
3. 确认所有数据验证下拉框已设置
4. 确认所有条件格式已应用
5. 确认冻结窗格已设置
6. 更新 `manifest.md` 和 `ai/outputs/index.md`

### 9.3 环境兼容

若当前环境无法生成 .xlsx 文件，按 `11-output-artifact-rules.md` 第 14 节环境兼容规则处理。
