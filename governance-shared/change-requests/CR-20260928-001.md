## Change Goal

已拆源可以声明自己不是需求文档。声明为 reference 的只编摘要页并写参见，不计缺口。没声明的仍要串上唯一需求和已有工包。口述日报进每人每天的待办；甩来的日报文件和开会文件拆进源文档存档。出文件前用路径校验器。技能缺口与「生成报告/导出」同现时走技能缺口行。

## Problem Statement

`compile_source_digests.py` 对全部已拆源执行同一套需求与工包判定。招标、硬件、密评等没有需求可绑，缺口挡住版本戳。底线 13 没有脚本。路由表里技能缺口行与「生成报告/导出」行同现时没有谁优先。

## Scope

`doc_kind`、reference 豁免、摘要页参见、路径校验器、日报与会议两路、路由裁决句。回归 Module 97。schema 保持 0.17.0。

## Non-goals

新建 `ai/wiki/`；按用词自动建边；代更 Grok 安装区；写入市监业务仓；把口语说法放进范围登记枚举；把所有 Markdown 写入收成脚本。

## Acceptance Criteria

1. 不写 `doc_kind` 的已拆源，缺口与 4.0.0 相同，串不完不盖戳。
2. `doc_kind: reference` 不计缺口，不改需求登记册，不追加 migration-log 与 pm-decisions。
3. 参见只收已存在的编号和标题完全相同的其他源。连跑两次摘要页字节不变。
4. 口述日报不建源目录。日报文件和开会文件拆进 `sources/` 且 `doc_kind: reference`，并仍提取进展或行动项。
5. 路径校验器对 `ai/outputs/` 放行，工作区根上的文件给出改放路径，事实源路径拒绝。
