## Change Goal

> 可验证目标：消除脚本层版本号硬编码分散与失步，引入单一版本源 `scripts/_version.py`；同时修复 `migrate_workspace.py --target-version` 被忽略的 bug。验收以端到端断言（target 实际写入、无 target 回落单一版本源、init 链路版本一致）通过为准。

## Problem Statement

当前问题（经 Agent A/B 双独立扫描核实，当前实际版本为 1.10.1）：
- 版本号硬编码分散且严重不同步：`config.py` `SKILL_VERSION="1.9.0"`（落后 2 版）、`migrate_workspace.py` `CURRENT_SKILL_VERSION="1.6.0"`（落后 4 版），而 `VERSION`/`SKILL.md`/`skill.json` 已是 1.10.1。
- `--target-version` 参数被忽略：`update_version_file()`/`append_migration_log()` 内部硬编码使用 `CURRENT_SKILL_VERSION`，导致打印显示目标版本、实际写入旧常量。
- `VERSION_CAPABILITIES` 表不完整：仅到 1.6.0，缺少 1.7.0~1.10.1 条目，迁移脚本无法检测这些版本的新增文件。
- `file_registry.py` 中 README 硬编码 `Skill 版本：0.4.0`/`Schema 0.2.0`（Agent A 扫描额外发现，纳入本次）。
