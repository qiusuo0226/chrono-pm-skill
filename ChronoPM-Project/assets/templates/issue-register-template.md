## 字段说明

| 字段 | 说明 | 取值 |
|------|------|------|
| 问题编号 | 唯一标识 | 新建 I-{YYYYMMDD}-{HHmmss}；存量旧编号 I-NNNN 保留不重编 |
| 关联风险 | 来源风险的ID | R-{YYYYMMDD}-{HHmmss}（可多个；存量 R-NNN 保留） |
| 来源 | 问题发现途径 | 日常例会发现 / 评审发现 / 风险转化 / 测试发现 / 客户反馈 |
| 问题类别 | 问题分类 | 技术类 / 进度类 / 资源类 / 需求类 / 质量类(defect) |
| 状态 | 当前状态 | 待处理 / 处理中 / 已关闭 |
| 问题描述 | 问题详细描述 | 自由文本 |
| 优先级 | 紧急程度 | 紧急（当天必须解决）/ 高（本周内）/ 中（两周内）/ 低（有空再处理） |
| 影响范围 | 受影响的模块或任务 | 自由文本 |
| 责任人 | 负责人 | 姓名（可多个） |
| 提出日期 | 发现日期 | YYYY-MM-DD |
| 解决方案 | 处理方式 | 详细描述 |
| 计划解决日期 | 计划完成日期 | YYYY-MM-DD |
| 实际解决日期 | 实际完成日期 | YYYY-MM-DD |
| 是否延期 | 是否超过计划日期 | 是 / 否 |
| 备注 | 补充信息（含跟踪记录） | 可用编号(1)(2)(3)记录多次跟进 |
