# Change Log 月份导航索引（change-log/index.md）

> 本文件是分层归档后 Change Log 的月份导航索引。路径：单项目 `change-log/index.md`，项目集 `ai/portfolio/change-log/index.md`。
> 活跃区 Change Log 超过 50 行或超过 30 天时，触发按月归档到 `change-log/archive/YYYYMM-change-log.md`，并在本索引登记。
> 维护规则见 `references/14-self-check-rules.md` §3.1（D12）与 `references/01-daily-report-rules.md`（归档触发检查）。

## 查询指引

- 近 30 天 / 活跃区：读活跃 Change Log。
- 历史：按月份定位 `change-log/archive/YYYYMM-change-log.md`，再按 Change ID 检索。
- 待确认：见 `pending-changes.md`（本索引不重复登记 pending）。
