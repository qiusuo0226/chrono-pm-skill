## 字段说明

| 字段 | 说明 | 取值 |
|------|------|------|
| Req ID | 需求唯一编号 | REQ-[模块代号]-NNN |
| 属性 | 需求类型 | 功能需求 / 非功能需求 / 约束需求 / 接口需求 / 数据需求 |
| 功能域 | 一级业务域 | 如：我要注销、我要变更、开办等 |
| 功能模块 | 二级功能模块 | 如：市场主体注销、市场主体变更 |
| 功能内容 | 具体功能点 | 如：农民专业合作社公示引导 |
| 功能描述 | 需求详细描述 | 自由文本 |
| 产品负责人 | 负责该需求的产品经理 | 姓名 |
| 优先级 | 业务优先级 | Must / Should / Could / Won't |
| 来源 | 需求来源 | contract / document / meeting / implied |
| Canonical ID | 跨源归并层指针（07 号 §8） | CAN-NNN / 无 |
| 范围归属 | 跨源范围判定（07 号 §8.5，与优先级独立） | in_contract / in_bid_only / in_initiation_only / not_in_scope / conflict |
| 所属迭代 | 关联的迭代ID | ITR-NN / 未分配 |
| 是否规划 | 是否已纳入规划 | 是 / 否 / 线上不支持 |
| 评审时间 | 需求评审日期 | YYYY-MM-DD |
| 规划备注 | 规划阶段的备注 | 自由文本 |
| 关联任务 | 对应开发任务 | T-YYYYMMDD-NNN |
| 关联里程碑 | 对应里程碑 | M-NN |
| 是否开发 | 是否进入开发 | 是 / 否 |
| 是否测试 | 是否进入测试 | 是 / 否 |
| 交付成果 | 交付物 | 代码 / 文档 / 接口等 |
| 验收标准 | 验收条件 | 可验证的描述 |
| 实现视图 | 面向开发的实现摘要（可选，07 号 §8.10 双视图） | 关键模块/接口名 + 一句话要点（≤100 字） |
| 原型/文档链接 | 关联的原型图/设计稿/接口文档指针（可选） | 外部路径 / URL / 无（原文档不入库） |
| 状态 | 需求状态 | proposed / confirmed / in_progress / delivered / accepted / changed / cancelled |
| Source | 来源说明 | 来源文件或会议 |
