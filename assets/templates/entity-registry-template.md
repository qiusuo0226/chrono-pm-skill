# 推导基线 — 实体登记册

> 本文件是推导基线的数据部分，记录项目管理的实体清单、生命周期阶段归属和关联任务。
> AI 在进行状态推导、实体枚举、进度判断时必须参考本文件。
> 通用推导规则见 `00-pm-main-rules.md` §10，本文件为项目级实例数据。

## 1. 实体清单

> **字段说明**：
> - "当前状态"指该实体的**生命周期阶段状态**（如"迭代一""需求评审通过""预演通过"），**不是**任务板状态（todo/in_progress/done）。两套维度独立，可能存在差异（如实体已"预演通过"但关联任务板仍 in_progress，此时触发 `00-pm-main-rules.md` §10.2 跨源矛盾处理）。
> - "关联任务/需求"列出与该实体直接关联的 Task ID 或 Requirement Ref，用于推导后定位受影响任务集（见 `00-pm-main-rules.md` §10.5）。

## 4. 更新规则

| 场景 | 触发条件 | 更新内容 |
|---|---|---|
| 新增实体 | 用户口述 / 需求评审 / 迭代规划 | 在对应模块追加实体行 |
| 阶段推进 | 日报/纪要中检测到终态事件 | 更新"当前状态"列 |
| 关联任务更新 | 任务看板变更 | 更新"关联任务/需求"列 |
| 终态事件触发回填 | 日报/纪要中检测到该实体的终态事件 | 若"关联任务/需求"列为空，AI 应 SUGGEST 回填（从 board 按实体名匹配关联任务），标注"AI 推断，待确认" |
| 模块新增 | 项目范围扩展 | 新增模块段落 |
