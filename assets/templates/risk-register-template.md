## 字段说明

| 字段 | 说明 | 取值 |
|------|------|------|
| 风险编号 | 唯一标识 | R-NNN |
| 关联问题 | 已转化为问题的ID | I-NNNN（多个用换行分隔） |
| 风险类别 | 风险维度 | 外部 / 技术 / 资源 / 质量 / 需求 / 进度 / 成本 / 合规 |
| 状态 | 当前状态 | 识别中 / 监控中 / 已关闭 / 已发生 |
| 风险描述 | 风险详细描述 | 自由文本 |
| 发生概率 | 发生可能性 | 高 / 中 / 低 |
| 影响程度 | 影响严重性 | 高 / 中 / 低 |
| 风险等级 | 综合等级 | 高 / 中 / 低 |
| 触发条件/预警信号 | 何时启动应对 | 具体描述 |
| 应对策略 | 应对方式 | 规避 / 转移 / 减轻 / 接受 |
| 应对措施 | 具体措施 | 详细描述（可换行） |
| 责任人 | 负责人 | 姓名 |
| 关联计划编号 | 关联的计划/迭代 | 如：全链通重构_编码和测试_阶段一 |
| 状态变更记录 | 状态变化历史 | 如：3/26 识别 -> 监控中 -> 6/12 发生 |
| 备注 | 补充信息 | 自由文本 |
