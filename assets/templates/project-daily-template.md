# 项目日报按需生成指引（模板）

> 依据升级方案需求 D（报告按需生成）与 references/01-daily-report-rules.md。项目日报**不再每日自动生成**，仅在 PM 需要时按此指引生成。数据源一律从待办文件实时聚合，不落盘为独立数据源。

## 1. 生成触发

- 仅当 PM 发起"项目日报 / 项目进展 / 今日项目情况"等查询时生成。
- 当天实时 / 历史日期缓存 / 跨日期范围三种场景均支持。

## 2. 数据源映射

| 报告段落 | 数据来源 | 说明 |
|---|---|---|
| 今日进展概要 | 当日待办文件（todos/{date}/）+ 各人工作日志 | 聚合各人完成情况 |
| 任务完成情况 | 待办文件 状态=已完成 | WP Ref 归组 |
| 进行中任务 | 待办文件 状态=进行中 | 按 WP Ref / 负责人归组 |
| 阻塞与问题 | 问题文件（issue-register）+ 待办 问题Ref | 引用 I-xxx |
| 新增风险 | 风险文件（risk-register）+ 待办 风险Ref | 引用 R-xxx |
| 里程碑影响 | PLAN 文件 WP（is_milestone=true）+ 所属阶段 | 引用 WP-NNN / M0X |
| 成本与工时 | 待办 预估/实际工时 → PLAN WP → budget | 联动 P&L（见 11.11） |
| 明日重点 | 待办文件 明日待办 | — |

## 3. 三种场景

1. **当天实时**：直接聚合当日待办文件，实时计算。
2. **历史日期缓存**：读取归档日报/历史待办（见 11.12 归档日报读取协议），升级前读 archive、升级后读 todos。
3. **跨日期范围**：升级前后数据源按"日期"统一拼接，并在输出标注各段数据源。

## 4. 生成输出骨架

| 段落 | 内容 |
|---|---|
| 项目 | [子项目名] / 日期 |
| 进展概要 | 一段话总结 |
| 完成 | 待办清单（已完成） |
| 进行中 | 待办清单（进行中）+ 预计完成 |
| 阻塞/风险/问题 | 引用 I-xxx / R-xxx |
| 里程碑 | WP-NNN / M0X 阶段状态 |
| 成本工时 | 预估/实际 → 偏差 |
| 明日重点 | 明日待办 |

## 5. 输出规范

- 只读查询，不修改任何源文件。
- 如生成为报告文件，存入 reports/ 并标记 `generated_from:` 源文件清单 + `updated:` 时间戳 + stale 失效规则（11.7.4 第2点）。
