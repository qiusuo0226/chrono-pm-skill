## 字段说明

| 字段 | 说明 | 取值 |
|------|------|------|
| 一级任务 | 阶段分类 | 如：启动阶段、需求规划与设计阶段、开发阶段、测试阶段 |
| 二级任务 | 具体任务 | 详细的任务描述 |
| 完成百分比 | 进度 | 0% - 100% |
| 人员 | 负责人 | 姓名（可多个，用逗号分隔） |
| 计划起始时间 | 开始日期 | YYYY/MM/DD 或 / |
| 计划截止时间 | 结束日期 | YYYY/MM/DD |
| 进度状态 | 任务状态 | 已完成 / 进行中 / 未开始 / 已搁置 |
| 达成标准 | 完成判定 | 如：代码审查通过、设计评审通过 |
| 交付物 | 产出物 | 如：代码、《需求文档》、原型、《评审问题跟踪表》 |
| 偏差说明/风险备注 | 偏差或风险 | 如：人员被抽调、开发质量返工。无偏差填 / |
| 整改措施/完成情况 | 纠偏措施 | 如：已协调资源、已修复。无填 / |
