# 集周报与资源变动检测（V-5）

## 1. 层级与路径

| 层级 | 路径 | 生成方 |
|------|------|--------|
| 成员项目周报 | `ai/projects/{名}/ai/reports/weekly/YYYY/YYYY-Wxx.md` | ChronoPM-Project（本包只读） |
| 项目集汇总周报 | `ai/portfolio/reports/weekly/YYYY/YYYY-Wxx.md` | 本包派生 |

生成链路：**各项目周报 → 集周报**。禁止把「从各项目日报现场拼集周报」当默认路径。各项目过程日志（`logs/ops/_index.md`）只作用量/漏条款查询，**不得**当进度事实写入集周报。

模板：`assets/templates/portfolio-weekly-template.md`。该模板仅用于 `portfolio/reports` 派生产物，不得当作改写成员项目周报的说明书。

## 2. V-5 硬约束：从项目周报往上摘

```
1. 读 project-index，取「是否纳入周报=是」且校验通过的一级成员
2. 对每个项目读取当期 YYYY-Wxx 周报（摘要行/章节标题级，最小读取集）
3. 按项目各一节：本周完成、风险、问题、里程碑、下周重点——摘项目周报，不复制全部明细
4. 合并跨项目事项（资源冲突、共性问题、需协调）
5. 人员/P&L/门禁按 02 号 / 05 号实时聚合，写入周报时作为当期快照
6. 落盘必须 generated_from（各项目周报路径清单）+ updated + stale
7. 不得自行确认；输出草稿，集经理确认后才把 status 改为已确认
```

引用的成员数据必须标注来源路径。跨项目事项单独成章。

纳入周报的项目不可遗漏：缺周报走 §3，不得从名单里删掉装成「本周无事」。

## 3. 缺周报降级

| 条件 | 行为 |
|------|------|
| 项目无当期周报 | **默认**提示「{项目} 周报未出，请先在该项目对话出周报」。集周报该节标「周报未出」，不编造进展 |
| 集经理明确指令「临时摘」 | 允许从该项目 `todos/{date}/{owner}.md` §3 工作日志现场拼一节，**必须标注「临时摘要，非替代周报」**。禁止把 `reports/daily/` 当个人日报内容源 |
| 无明确指令 | 禁止从日报拼；禁止用上上周报冒充本期 |

「临时摘」只覆盖被点名或确认允许降级的项目，其他项目仍走周报。临时摘要不得去掉标注后当正式周报源再次引用。

## 4. 集周报内容下限

必须覆盖：

1. 各纳入项目一句话概要 + 里程碑/风险等级（有则摘）。
2. 跨项目事项：项目周报中标注跨项目的需协调项、各项目待办 §0.5 本周进出组 + `_index` §1 花名册变动、跨项目风险（02 号 V-4）。
3. 资源全景：实时聚合，不把配置率写回 shared-resource-index。
4. 整体 P&L：实时读各 budget。
5. 信息来源段：列出 generated_from。

AI 不得自行把草稿标为已确认。

## 5. 资源变动检测（只读提示）

承接原 01 号 §1.4 的集层职责：在生成集周报、或集经理投喂跨项目汇报/纪要摘要时，扫描资源变动信号。

| 触发关键词 | 意图 | 本包动作 |
|---|---|---|
| 被抽调 / 借调 / 调往 / 支援其他项目 | 流出 | 内部 V-9 → 流出项目 `_index` §1 + 待办 §0.5 |
| 新增人员 / 加入团队 / 报到 / 到岗 | 流入 | 内部 V-9 → 流入项目 `_index` §1 + 待办 §0.5 |
| 请假 / 休假 / 产假 / 病假 / 事假 | 临时不可用 | 提示状态 + 是否缺 B 角 |
| 离职 / 辞职 / 离场 / 退出 | 永久流出 | 内部 V-9 → `_index` §1 + 待办 §0.5 + 交接风险 |
| 转岗 / 岗位变更 / 换项目 | 岗位变更 | 内部 V-9 → `_index` §1 岗位/状态 + 待办 §0.5 |
| 兼顾 / 兼任 / 同时负责 | 分配变更 | 提示兼职 + 评估合计比例 |

规则：

1. **不得**改任何项目的 `_index` / 待办 §0.5（含已退役的 resource-register / transfer-log）。只出内部 V-9。对外白话，不对用户说「建议更新清单」。
2. 汇报中出现未入花名册人员 → 「候选资源变更」，不得自动加为正式成员。
3. 流出涉及关键路径唯一负责人且无 B 角 → 高优先级警告。
4. 某项目在岗可用人力低于该项目计划资源下限（无则仅提示「无法核对容忍度」）→ 标注资源风险触发，建议主归属项目记风险（仍走内部 V-9，不代写）。

周报/资源变动的人员数据源 = 各项目待办 **§0.5** + `_index` **§1** 花名册。

输出列：`来源 | 当前状态 | 一致性判断 | 建议操作`，对内再附 `目标项目 | 目标文件 | 建议动作 | 原因 | 优先级`。
