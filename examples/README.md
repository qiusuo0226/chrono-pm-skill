助手提问的规矩（所有示例都这样）：

```text
N. 一句话背景
   我建议：……
   A. ……（选了之后会……）
   B. ……（选了之后会……）
   C. 先放着，这题以后再说

你回：1A；2B；3C
```

同一轮可以一次回多题。已经点过头的，助手不会再问。
